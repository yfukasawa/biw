Important

Loop and Iteration#

先週は条件分岐(ifとインデント)を学びましたが、今週はループというものについて学びます。
一番プログラミングらしく、ここの理解は最重要です。ここを覚えると実用的になっていきます。
同じ処理を繰り返し行いたいときに使います。

for文#

Hint

ここが自動化の肝です。繰り返し作業を日常の中でも見つけてみましょう。

以下を実行してみましょう。

for i in range(0,11):
    print(i)
print("Finished.")

range関数はPythonのループなどでよく使います。range(start, stop)でstartの数字からstopまでの 数字が生成されます。stopは含まれません。 0からのスタートで良いときはシンプルにrange(stop)も可能です。

range(start, stop): start ≦ i < stop
range(stop): 0 ≦ i < stop

forではリストの処理をよく行います。

以下を実行してみましょう。

l = ["virus", "bacteria", "archaea", "amoeba"]
for name in l:
    print(name)
print("Finished.")

lというリストの中身を1つずつnameに入れてブロックに書かれた処理を行っていきます。
ブロックについては前回学びました。

演習1

  1. 新しいリストを作成しましょう。

  2. forループで中身を１つずつ表示させてください。

  3. 自分のプロダクトで「繰り返したい処理」は何でしょうか。1行で書いてみてください。

数えるループ#

ループと条件分岐(if)を組み合わせると、条件に合うものがいくつあるか数えることができます。
プロダクトでも「足りない試薬が何件あるか」のように、数える処理はよく使います。

リストの中に”ATG”がいくつあるか数えてみましょう。

l = ["AAG", "ACG", "GGG", "GCG", "ATG", "TGA", "ATG"]
count = 0
for triplet in l:
    if triplet == "ATG":
        count = count + 1
print(count)

次の3つの順番がポイントです。

  1. ループの前に、数える変数を0で用意する(count = 0)

  2. ループの中で、条件に合うたびに1増やす(count = count + 1)

  3. ループの後で、結果を使う(print(count))

print(count)のインデントをforと同じ位置にしている点にも注目してください。
ループの中に入れると、どうなるでしょうか。実際に試して確認しましょう。

演習2

  1. 上のリストで、Gを含むトリプレットがいくつあるか数えてください。(ヒント: "G" in triplet)

  2. 自分のプロダクトで使うデータを、リストとして書いてみましょう。その中で「数えたいもの」を数えるコードを書いてください。

break文#

ループを終わらせる方法の一つにbreakというものがあります。
普通に全部繰り返す必要がないときなどに使ったりします。

例えばリストに”ATG”という文字列が含まれているかどうか知りたいとします。見つかった時点で、以降を調べる必要はありません。

l = ["AAG", "ACG", "GGG", "GCG", "ATG", "TGA"]
for triplet in l:
    if triplet == "ATG":
        print("あった")
        break
print("Finished.")

演習3

先程の演習1で作ったループをifの条件分岐とbreak文を使って早く終わらせてみてください。

while#

Pythonではforほどは使いませんがwhileループというものもあります。
whileは条件判定をしながら、条件がTrueであり続ける限りブロックを実行します。

num = 0
while num < 100:
    num = num + 1
    print("Running")
print("Finished.")

これで実行できますが、上と下の違いは分かるでしょうか。

num = 0
while num < 100:
    num = num + 1
    print("Running")
    num = num - 1
print("Finished.")

下の方はは永遠に終わりません。いわゆるバグったコードの例になります。
numが増えないのでずっとwhileが実行されます。

こういうものもあると覚えておいていただければ今はいいです。

Hint

プログラムが終わらなくなったときは、ターミナルでCtrl + Cを押すと止められます。

AIと一緒に書く: 予測してから実行する#

AIにループのコードを書いてもらうことは簡単です。しかし、出力を予測できないコードは、自分で説明できません。
次の手順で、AIのコードを自分のものにしましょう。

  1. 自分のプロダクトで使うデータ(リストか辞書)をAIに見せて、「この中の〇〇を数えるPythonコードを書いてください」と頼む

  2. 実行する前に、出力がどうなるかを予測して書いておく

  3. 実行して、予測と比べる

  4. 違っていたら、どの行の理解が違っていたのかを考える

  5. 全ての行を、自分の言葉で説明できるか確認する

Note

AIが書くコードには、今日学んでいない書き方が含まれることがあります。わからない行は、そのままにせずAIに質問しましょう。

今週はここまでです。お疲れさまでした。

Important

自分のプロダクトで使うデータを、リストか辞書としてコードに直接書き、ループで「数える」プログラムを作ってきてください。
AIを使っても構いませんが、全ての行を自分で説明できるようにしてください。

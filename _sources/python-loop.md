## for文
```{hint}
ここが自動化の肝です。繰り返し作業を日常の中でも見つけてみましょう。
```

以下を実行してみましょう。

```{code-block}
for i in range(0,11):
    print(i)
print("Finished.")
```

`range`関数はPythonのループなどでよく使います。`range(start, stop)`でstartの数字からstopまでの
数字が生成されます。stopは**含まれません**。
0からのスタートで良いときはシンプルに`range(stop)`も可能です。

range(start, stop): start ≦ i **<** stop  
range(stop): 0 ≦ i **<** stop

forではリストの処理をよく行います。  

以下を実行してみましょう。

```{code-block}
l = ["virus", "bacteria", "archaea", "amoeba"]
for name in l:
    print(name)
print("Finished.")
```

`l`というリストの中身を1つずつ`name`に入れてブロックに書かれた処理を行っていきます。  
ブロックについては前回学びました。

## 数えるループ

ループと条件分岐(`if`)を組み合わせると、**条件に合うものがいくつあるか数える**ことができます。  
プロダクトでも「足りない試薬が何件あるか」のように、数える処理はよく使います。

リストの中に"ATG"がいくつあるか数えてみましょう。

```{code-block}
l = ["AAG", "ACG", "GGG", "GCG", "ATG", "TGA", "ATG"]
count = 0
for triplet in l:
    if triplet == "ATG":
        count = count + 1
print(count)
```

次の3つの順番がポイントです。

1. ループの**前**に、数える変数を`0`で用意する(`count = 0`)
2. ループの**中**で、条件に合うたびに`1`増やす(`count = count + 1`)
3. ループの**後**で、結果を使う(`print(count)`)

`print(count)`のインデントを`for`と同じ位置にしている点にも注目してください。  
ループの中に入れると、どうなるでしょうか。実際に試して確認しましょう。

## break文

ループを終わらせる方法の一つに`break`というものがあります。  
普通に全部繰り返す必要がないときなどに使ったりします。  

例えばリストに"ATG"という文字列が含まれているかどうか知りたいとします。見つかった時点で、以降を調べる必要はありません。

```{code-block}
l = ["AAG", "ACG", "GGG", "GCG", "ATG", "TGA"]
for triplet in l:
    if triplet == "ATG":
        print("あった")
        break
print("Finished.")
```

## while
Pythonでは`for`ほどは使いませんが`while`ループというものもあります。  
whileは条件判定をしながら、条件が`True`であり続ける限りブロックを実行します。  

```{code-block}
num = 0
while num < 100:
    num = num + 1
    print("Running")
print("Finished.")
```

これで実行できますが、上と下の違いは分かるでしょうか。

```{code-block}
num = 0
while num < 100:
    num = num + 1
    print("Running")
    num = num - 1
print("Finished.")
```

下の方はは永遠に終わりません。いわゆるバグったコードの例になります。  
numが増えないのでずっと`while`が実行されます。  

こういうものもあると覚えておいていただければ今はいいです。  

```{hint}
プログラムが終わらなくなったときは、ターミナルで`Ctrl + C`を押すと止められます。
```

## AIと一緒に書く: 予測してから実行する

AIにループのコードを書いてもらうことは簡単です。しかし、**出力を予測できないコードは、自分で説明できません**。  
次の手順で、AIのコードを自分のものにしましょう。

1. 自分のプロダクトで使うデータ(リストか辞書)をAIに見せて、「この中の〇〇を数えるPythonコードを書いてください」と頼む
2. **実行する前に**、出力がどうなるかを予測して書いておく
3. 実行して、予測と比べる
4. 違っていたら、どの行の理解が違っていたのかを考える
5. 全ての行を、自分の言葉で説明できるか確認する

```{note}
AIが書くコードには、今日学んでいない書き方が含まれることがあります。わからない行は、そのままにせずAIに質問しましょう。
```
